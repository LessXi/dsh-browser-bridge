DSH Browser Bridge

This extension lets a DeepSeek Harness session read and operate pages in your own Chrome — including sites you are already signed in to.

Before you connect

The debugger permission is equivalent to being able to read and change your data on every site, including signed-in sessions. The harness asks you before it touches each new site, and you can switch the bridge off entirely from DSH Settings → Plugins.

Connection

The port shown in the harness URL, usually 3080.

Open DSH, go to Settings → Plugins → browser-bridge, and copy the token. It is stored only in this browser profile.

Off by default. With it off, you choose what to send from the right-click menu, so merely highlighting text to copy it never reaches the model.

File uploads

To let DSH upload a file through a page, Chrome needs one setting this extension cannot grant for itself: open chrome://extensions, find this extension, choose Details, and turn on Allow access to file URLs.

How this stays under your control
  1. The bridge listens on loopback only, and this extension proves itself with a token.
  2. Every new site needs your approval before DSH may read or act on it.
  3. Submitting forms, purchasing, and deleting ask a second time.
  4. Browser history is never remembered as allowed — every read asks again.
  5. No page content is ever sent anywhere except to your own harness.
